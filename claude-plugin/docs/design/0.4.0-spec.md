# RePoG plugin 0.4.0: implementation spec

The persistence order below (reply, commit, hand-back line) and the `now_append`
warning were withdrawn in 0.4.1; see `0.4.1-notes.md`.

Source: the G2 review (`dist/reviews/g2/rapor.md`, not committed), 251 turns of a
Turkish One Piece campaign on 0.3.0. The maintainer accepted every proposal on
2026-11-04, plus one addition: campaign records are written in the play language.

## 0. The rule behind 0.4.0

Everything wired deterministically worked in G2; everything left to the model's
memory did not. So every behavior in this release is either:
- enforced or triggered by the writer or a hook, or
- removed.

Three further rules follow:
- A passive label is not an instruction; a mismatch must be detected and
  reported.
- A healthy campaign carries zero standing warnings; findings the Player has
  accepted can be acknowledged.
- Gates check effect, not ceremony.

## 1. Packages and file ownership

Each package edits only the files it owns, plus the test files named for it. A
package that needs a change in a file it does not own uses the contract in §2. If
the contract is not enough, it codes against the contract with a safe fallback
(`getattr`, try/except) and reports the gap.

Common rules for every package:
- **Line endings.** Keep each file's line endings byte-exact. Many files are CRLF and some are mixed. Patch CRLF files with a byte-level script, never with a tool that rewrites line endings.
- **Byte budget.** `plugin/skills/play/SKILL.md` must stay at or under 19,000 bytes, and its embedded AGENTS section must equal `plugin/AGENTS.md`. Both belong to I.
- **The curator agent.** The body of `plugin/agents/repog-curator.md` must stay under 4,096 bytes.
- **Fixtures.** Tests use synthetic content only. Never read, copy or write the user's live game folders.
- **Compatibility.** New payload fields are optional unless this spec says required. Existing callers keep working.
- **Language-specific text.** It goes in language packs (owned by L) or in small per-code tables inside the owning tool, falling back to English.
- **Helpers stay semantic-free.** They detect, count, compare and move text, and never invent fiction.
- **Testing.** Run your own tests with `python -m pytest -q -p no:cacheprovider tests/<file>`. If a failure comes from a file another package is editing, rerun once, then report it instead of editing that file.

## 2. Cross-package contracts

### 2.1 Runtime records (`campaign/.repog-runtime/`)

- **`curation_due.json`.** Written by W, read by K.
  - Shape: `{"at": iso, "revision": int, "targets": [{"path": str, "rule": str, "reason": str}]}`.
  - W writes it at commit-distill, from:
    - the targets in `deferred_reconcile`;
    - the warnings `death_projection`, `now_overflow`, `records_language_mismatch`, `stacked_sections` and `note_core_missing` found by its post-commit check.
  - W removes a target when a later commit-distill or commit-curation changes that path, and deletes the file when no target remains.
  - K shows, while the file exists and on every capsule (full or delta): `[curation] due: N files (a, b, …): build the packet (curation packet) and launch repog:repog-curator in the background`, or with `boundary_curator: inline`, `fold them at the next distill`.
- **`order_last.json`.** Written by K's Stop hook.
  - Shape: `{"at", "prompt_uuid", "expected": "narrate_then_commit"|"commit_then_narrate", "observed": "narrate_first"|"commit_first"|"no_commit", "final_text": bool}`.
  - K's capsule shows `[order] last reply committed before narrating: send the reply first, then one commit, then the hand-back line` only when observed is `commit_first` and expected is `narrate_then_commit`. It also shows `[order] last turn ended with no visible text: end with the hand-back line` when `final_text` is false.
- **`lint_history.jsonl`.** Written by L.
  - L stops storing `prompt_sample` and stores `prompt_language` (a code) instead.
  - L keeps reading only the current turn of the transcript, and never stores reply or prompt text beyond short finding snippets in `lint_last.json`.
- **`presentation_lint.top_habits(campaign: Path, last: int = 20, limit: int = 3) -> list[dict]`.** Provided by L.
  - Returns `{"rule", "label", "count", "example"}` items: the rules flagged most often in the last `last` linted replies.
  - Gesture families count as one rule each, with the family name as the label.
  - K renders `[habits] last 20 replies: label (n), label (n)` in full capsules, and in deltas when the list changed.
- **`presentation_lint.report_summary(campaign: Path, last: int = 20) -> dict`.** Provided by L.
  - Returns `{"replies": int, "rules": {rule: count}, "top": [...], "text": str}`, where `text` is at most 600 characters.
  - W includes it as `lint_report` in the commit-distill result.

### 2.2 Roll receipts (D, read by W and C)

New receipt fields:
- `reachable_bands` (list, best first), `floor_band`, `ceiling_band`;
- `p_below_success`: the probability that the result lands in a band below the lowest success band;
- `certain` (bool), `display` (the Player-facing line, in the play language), and `summary` (one line: `ok <band> margin <m>`).

How certainty works:
- A call is `certain` when its floor band is a success band.
- A certain call is recorded as `auto: true` with the band set to the **floor band**, not the top band. The same applies to `auto_success_margin`.
- The result's `warnings` include `roll_certain` with a suggestion to narrate the result without rolling.

New CLI subcommands:
- `roll_dice --campaign C axes --since-revision N`: counts per actor and axis of receipts at or after N.
- `roll_dice --campaign C reread --input-file -` with `{roll_id, reason, new_band}`: appends a row `{"kind": "reread", "reread_of", "reason", "new_band", "revision", "at"}`.

Reread rows are never open receipts and are never cited. `open_receipts` and `find_receipt` skip them.

### 2.3 Writer payload changes (W; documented by P and I)

All of these are backward compatible.

- **`expected_continuity_revision: "current"`.** Accepted by commit-distill only.
- **`next_expected_revision`.** Every result (durable, checkpoint, distill, curation) includes it.
- **`deferred_reconcile`.** commit-distill accepts `[{"path", "reason"}]`. These targets go to `curation_due.json` and do not count as unreconciled.
- **Distill gate.** Before applying, commit-distill runs `check_campaign(scope="full")` on the current files and collects findings whose rule is in `DISTILL_GATE_RULES`:
  - `cast_dead_listed`, `cast_present_missing`, `relationship_dead_active`, `location_unmapped`, `stacked_sections`, `now_overflow`, `minor_romance_history`.
  - If any gated finding's path is neither mutated by this payload nor listed in `deferred_reconcile`, the distill is refused with `failure_category: "distill_unreconciled"` and a list of `{path, rule, message}`.
  - `minor_romance_history` cannot be deferred.
- **Session log rotation.**
  - commit-distill rotates automatically when `session_log.md` is over 150,000 characters, as if `rotate_log` were true. `rotate_log: false` still forces no rotation.
  - Archive name collisions get a `-2`, `-3`, … suffix.
- **Receipt trimming.** Durable receipts omit lines whose value is `none` or empty, such as `Deferred propagation: none`. The log parsers must keep accepting both forms.
- **`## Now` overflow.**
  - Applies after mutations, to `characters/`, `places/` and `factions/` notes.
  - The `## Now` section is over budget when it exceeds 800 characters or holds more than 3 dated entries. A dated entry is a line or bullet starting with a day marker in any pack language (`Day 12`, `Gün 12`, `Tag 12`, `Día 12`, `Jour 12`), or containing `(day N)`.
  - The writer moves the oldest dated entries into `## History`, creating that section right after `## Now` when it is missing, until the section is within budget. Undated lines stay.
  - The result's `warnings` get `now_overflow_folded` with the path and count.
  - An `append` op targeting `## Now` adds the warning `now_append`: use `replace_section` and keep the current state only.
- **`death_projection`.** When a mutation sets a note's Core `- Status:` to `dead` or `missing`, the writer looks in `active_cast.md` and `relationship_map.md` for rows naming the note's title that this payload did not change. If it finds any, it adds this warning, listing the rows; the path also goes to `curation_due` at the next distill.
- **`open_choices` at a scene checkpoint.**
  - A `checkpoint` with `boundary: "scene_checkpoint"` must include `open_choices`, a list of 1 to 5 short strings. The writer replaces `current_state.yaml` `open_choices` with them.
  - Missing at a scene checkpoint: refused with `checkpoint_open_choices_missing`. Optional elsewhere.
- **`inventory_count_duplicate`.** Warned when a `current_state.yaml` inventory line carries a number for an item tracked in `mechanics_state.json`. The line should name the item only.
- **`cost_unrecorded`.** Warned when a change cites a roll whose `outcome` is `success_with_cost`, `partial_or_loss` or `failure`, and the payload changes none of:
  - `current_state.yaml` `player.conditions` or `pending_consequences`;
  - `mechanics_state.json` (mechanic operations);
  - a character note.
- **Active-cast handoff error.** When a checkpoint handoff lacks an `active_cast.md` mutation, the error carries a ready `upsert_row` op built from the handoff names and the table's columns.
- **Relationship ownership error.** It now says to add `relationship_map.md` to the owners. It no longer suggests changing the kind.
- **`rpg_state campaign template --kind durable|checkpoint|distill`.** Prints a JSON skeleton containing:
  - the current revision;
  - `operation_id` placeholder;
  - valid `scene_mode` values;
  - `current_state.yaml` top-level keys;
  - the columns of `active_cast.md` and `relationship_map.md`;
  - the owner each change kind requires.

  The helper is read-only.
- **Encoding.**
  - `--input-file` decodes UTF-8 (with or without BOM). It falls back to cp1254, then latin-1, adding the warning `input_decoded_<codec>`.
  - `repog.sh` exports `PYTHONUTF8=1` and `PYTHONIOENCODING=utf-8`.
- **Unicode keys.** `owner_ops` key paths accept Unicode identifiers (`player.stats.Algı`) and quoted segments with spaces (`player.stats."Sokak Zekâsı"`).
- **`commit-act`.** A typed act transition: `rpg_state campaign commit-act --input-file -`.
  - Payload: `{operation_id, expected_continuity_revision, close: {act_id, outcome, summary}, open: {act_id, title, scope, closure_conditions: [..], prepared_expectations: [..]?}, checkpoint: {...}}`.
  - It builds the `threads.md` Arc Compass and Act Archive mutations the full check requires, and commits them as one durable transaction at a scene-checkpoint boundary.
  - It reads `check_state`'s threads rules to stay valid.
- **`glossary_suggest`.** Advisory. A new note whose title contains a word not in the play language, or a note created in a language other than the play language, gets a suggested `glossary.md` row `{Term, Preferred, Variants, Notes}` in `warnings`.
- **`record_language`.** Advisory. When `create_text`, `replace_section` or `append` text (headings, `- Label:` prefixes and table headers excluded) is detected as a language other than the records language, the result warns with the path. The records language is `narration.records_language`, or `narration.language` when that field is `same` or missing.
- **`lint_report`.** Included in the commit-distill result (see §2.1).

### 2.4 Directive acknowledgement (C reads, P documents)

A `directives.md` row whose Scope is `check` and whose Directive begins with
`acknowledge <rule_id>`, optionally followed by `for <path or name>`, turns
matching full-check findings from warning into info. The message gets
` (acknowledged by D-00N)`. Only warnings can be acknowledged, never errors.

### 2.5 Records language

- `play_profile.yaml` `narration:` gains `records_language: same`, which may also be a language code.
- **S:** Session 0 settles the play language in stage 1, before any content is written. From then on it writes every record's content in that language.
- **P and I:** Every record's content is written in the records language. That covers descriptions, `## Now` and History lines, Depth, Agency Card values, summaries, facts, thread text and names. The structure stays exactly as the templates write it: file names, YAML keys, headings, `- Label:` names, table headers, enum values (`alive`, `dead`, scene modes, band names), ids and op names.
- **C:** `records_language_mismatch` is one aggregated warning listing the files whose body text is detected confidently in another language. Bodies are sampled with headings, labels, table headers and names stripped. It is not a distill gate.
- **K:** The capsule shows note text as stored. It may localize its own fixed labels through the pack when a pack provides them.

### 2.6 Age rule (L, C, P, S, I)

- **The rule.** No character's romantic or sexual relationship, past or present, may begin before 18. Age and duration arithmetic must not imply it. When a character's age changes, re-check their dated history.
- **L.** Lint rule `minor_sexual_proximity`, always first in the summary. It flags an under-18 age expression within 2 sentences (or 220 characters) of a romance or sex term.
  - Pack keys: `age_patterns` (regexes) and `romance_terms`.
  - Age expressions: `at fifteen`, `aged 15`, `15-year-old`, `fifteen years old`, `on beş yaşında`, `on beşimde`/`on beşimdeyken`, `15 yaşında`.
  - Durations (`fifteen years ago`, `on beş yıl`) are excluded.
- **C.** Warning `minor_romance_history` for the same proximity in character notes. This gate cannot be deferred at distill.
- **P.** A one-line rule in the character template's Depth/History guidance.
- **S.** A fixed row in `boundaries.md`.
- **I.** The rule in SKILL.md, in the Adults And Content section.

### 6.2 `presentation_lint.py` changes

- **Gesture families** (`gesture_repeat`), counted by stem and family:

  - `bir şey demiyor`.

  Families live in the pack (`gesture_families`). A family flags when it appears in 3 or more of the last 10 replies.
- **Case slips.**
  - `dotless_capital`: a sentence-initial `I` followed by Turkish letters (`Ilk`, `Ikinci`).
  - `name_case_mismatch`: `İlse` versus the card's `Ilse`.
- **`foreign_short_line`.** A line of 2 or more words made only of English stopwords and words (`Now the distill.`).
- **Name exclusions.** Exclude cast, glossary and place names from language detection and from repetition n-grams. Strip suffixes after an apostrophe before matching.
- **OOC turns.** For a turn whose prompt starts with OOC, lint the prose outside the OOC block. An `(OOC: …)` parenthetical in the reply is excluded.
- **`npc_echo`.** `diye tekrarlıyor`/`tekrar ediyor`/`yineliyor` (and English `repeats`/`echoes`) within 6 words of a prompt content word.
- **Paraphrased restatement.** The first sentence shares 2 or more content stems with the prompt and has a second-person verb (`-sun`, `-sın`, `-yorsun`, …).
- **`pc_line_rewritten`.** A quoted line attributed to the PC (`diyorsun`, `you say`) whose content words do not appear in the prompt is fabricated when the prompt has no quote, and rewritten when the prompt quotes something else.
- **`tool_description_leak`.** A tool description containing a cast name, or a pack `secret_words` term (`sır`, `gizli`, `secret`).
- **`minor_sexual_proximity`** (§2.6).
- **Privacy.**
  - Remove `prompt_sample` from history; store `prompt_language`.
  - Keep reading only the current turn.
  - Document in the module docstring that the hook reads the current session's last turn locally and stores counts and short snippets only.
